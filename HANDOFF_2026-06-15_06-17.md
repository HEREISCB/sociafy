## Goal
User reported the calendar feature "doesn't work" — clicking a slot was supposed
to open a modal to generate a post and schedule it, but nothing happened. Asked
to find and fix this and other site-wide issues.

## Root cause (NOT a code bug)
The OpenAI account behind `OPENAI_API_KEY` is **out of quota**. Every AI
generation in the app fails with `429 insufficient_quota`. Reproduced by calling
`generateCompose()` directly with the prod env. Production DB confirms a paying
user (5,000 credits) had two compose attempts charged + auto-refunded with
`compose_generation_failed` on 2026-06-09. **Fix is external:** add funds at
platform.openai.com → Billing, and confirm Vercel prod uses the same key.

Other users in the DB sit at **0 credits** (signup bonus was removed), so they'll
hit `insufficient_credits` even after the OpenAI top-up.

## Files changed
- [lib/api.ts](lib/api.ts) — new `aiProviderHint()` maps OpenAI `insufficient_quota`
  / `invalid_api_key` / 429 to a clean **503 `ai_unavailable`** with a human hint,
  instead of the generic 500 that read as "Failed: 500" in the UI.
- [app/api/schedule/route.ts](app/api/schedule/route.ts) — schedule POST used to
  silently skip platforms with no connected account and return 200 `{scheduled:[]}`,
  so the modal lied "Scheduled." Now returns **400 `no_connected_accounts`** when all
  platforms are unconnected, and reports partial `skipped[]` on success.
- [app/api/compose/variants/route.ts](app/api/compose/variants/route.ts) — refund the
  full reservation when the result is a **stub fallback** (no real AI ran), so users
  aren't charged a credit for canned text.
- [lib/ai/compose.ts](lib/ai/compose.ts) — fast-path Responses call: raised
  `max_output_tokens` 1500→3000 and added `reasoning: { effort: 'low' }` for gpt-5
  models so the JSON answer isn't truncated into a silent stub.
- [components/calendar.tsx](components/calendar.tsx) — new `friendlyApiError()` turns
  raw `"<status>: <body>"` throws into actionable copy (top-up / provider-down /
  session-expired); quick-schedule now surfaces `skipped[]` platforms.
- [components/compose.tsx](components/compose.tsx) — compose page reads the structured
  503 `{hint}` body and shows "AI generation is temporarily unavailable" instead of
  "Sign in to generate real variants" (which was wrong for a 503).
- [lib/api.test.ts](lib/api.test.ts) — **new** unit tests for `aiProviderHint()`
  (quota, invalid key, plain 429, pass-through). 4 tests.
- [drizzle/0007_billing_providers.sql](drizzle/0007_billing_providers.sql) —
  pre-existing uncommitted change (comment lines removed), **not from this session**;
  carried along per "push all the changes".
